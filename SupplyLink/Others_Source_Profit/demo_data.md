# SupplyLink - Others Source Profit (Demo Data Guide)

## সিস্টেমের স্বয়ংক্রিয় কার্যক্রম (Auto Lifecycle):
1. **ক্যাশ আউট:** অ্যাসেট ক্রয় বা শেয়ার ইনভেস্ট করলে সরাসরি `cash` টেবিলে `out` টাইপে জমা হয়।
2. **ক্যাশ ইন:** মাসিক ভাড়া, লভ্যাংশ বা অ্যাসেট বিক্রি করলে ক্যাশে `in` টাইপে জমা হয়।
3. **ক্যাপিটাল গেইন প্রফিট:** ক্রয়মূল্যের চেয়ে বেশিতে অ্যাসেট বিক্রি করলে অতিরিক্ত টাকা স্বয়ংক্রিয়ভাবে প্রফিট হিসেবে ইনভেস্টর ডিস্ট্রিবিউশনে যুক্ত হয়।
4. **ইমেইল অ্যালার্ট:** প্রতিবার কেনা, চুক্তি, ভাড়া কালেকশন, লভ্যাংশ বা বিক্রির সময় সরাসরি অ্যাডমিন ইমেইলে (`supplylinkb@gmail.com`) প্রফেশনাল এইচটিএমএল রিপোর্ট সেন্ড হয়।
5. **LuxuryToast:** ইন্টারফেসে প্রতিটি সফল বা ব্যর্থ অপারেশনের জন্য প্রিমিয়াম নোটিফিকেশন প্রদর্শন করে।
