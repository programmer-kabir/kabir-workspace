# ⚙️ SERVER (Backend & API Engine)

এই ফোল্ডারে সাইটের ব্যাকএন্ড এপিআই ও সেন্ট্রাল বিজনেস লজিক থাকবে।

### ফোল্ডার পরিচিতি:
- **`config/`**: ডাটাবেজ কানেকশন (Firebase Admin SDK, MongoDB, ইত্যাদি) ও সিক্রেট এনভায়রনমেন্ট ভেরিয়েবল।
- **`routes/`**: সব API এন্ডপয়েন্ট (যেমন `/api/orders`, `/api/verify-trx`, `/api/player-check`)।
- **`controllers/`**: রিকোয়েস্ট হ্যান্ডলিং ও ডাটা প্রসেসিং লজিক।
- **`services/`**: পেমেন্ট গেটওয়ে ভেরিফিকেশন, ইন-গেম ডায়মন্ড অটো ডেলিভারি স্ক্রিপ্ট ও এসএমএস অ্যালার্ট।

> [!NOTE]
> এখানে কোনো ইউজার ইন্টারফেস (UI) বা HTML থাকবে না। এটি শুধুমাত্র ব্যাকএন্ড সার্ভার।
