# ⚡ TopUp BD - Premium Gaming Top-Up Platform

TopupShop ও UCGhor-এর চেয়ে উন্নত, আধুনিক এবং সম্পূর্ণ ফ্রিতে ফায়ারবেসে (Firebase Spark Free Tier) হোস্ট করার উপযোগী একটি প্রিমিয়াম গেম টপ-আপ ওয়েবসাইট।

---

## 🌟 স্পেশাল ফিচারসমূহ (Key Features)

1. **Player Nickname Auto-Preview (UID যাচাইকরণ):**
   - ইউজার Player UID দেওয়ার পর **"নাম চেক"** বাটনে ক্লিক করলে সিস্টেম স্বয়ংক্রিয়ভাবে গেমারের In-Game Nickname (যেমন: `亗_MAFIA_BOSS_亗`) এবং সার্ভার প্রদর্শন করে। ফলে ভুল অ্যাকাউন্টে টপ-আপের ঝুঁকি থাকে না।
2. **১-ক্লিক ইনস্ট্যান্ট ওয়ালেট পারচেজ (Instant 1-Click Purchase):**
   - ইউজার ওয়ালেটে ব্যালেন্স ডিপোজিট করে রাখলে কোনো পেমেন্ট গেটওয়ের ঝামেলা ছাড়াই মাত্র ১ ক্লিকে ০ সেকেন্ডে ডায়মন্ড কিনতে পারে।
3. **MFS পেমেন্ট গেটওয়ে (bKash, Nagad, Rocket):**
   - ওয়ান-ট্যাপ সেন্ড মানি নাম্বার কপি, TrxID ভেরিফিকেশন এবং সহজ ইউজার এক্সপেরিয়েন্স।
4. **অফিসিয়াল ডিজিটাল ক্যাশ মেমো (Printable Invoice Slip):**
   - অর্ডার সম্পন্ন হওয়ার পর বারকোড ও অর্ডার আইডিসহ ডিজিটাল ক্যাশ মেমো প্রিন্ট বা শেয়ার করার সুবিধা।
5. **লাইভ সাম্প্রতিক অর্ডার স্ট্রিম (Realtime Ticker):**
   - অন্যান্য গেমারদের লাইভ পারচেজ হিস্ট্রি ও ডেলিভারি স্ট্যাটাস।
6. **অ্যাডমিন কন্ট্রোল সেন্টার (Admin Dashboard):**
   - পিন: `7788` দিয়ে হেডার থেকে অ্যাডমিন প্যানেল ওপেন করা যায়।
   - মোট সেলস ও অর্ডার রেভিনিউ ট্র্যাকিং।
   - ১ ক্লিকে অর্ডার স্ট্যাটাস চেঞ্জ (`Completed`, `Processing`, `Refunded`)।
   - লাইভ ওয়েবসাইট স্ক্রোলিং নোটিশ এডিটর।
   - ইউজার ওয়ালেটে ক্রেডিট যোগ করার সুবিধা।
7. **PWA সাপোর্টেড (মোবাইল অ্যাপের মতো ইনস্টলযোগ্য):**
   - প্লে স্টোরের $25 ফি ছাড়াই গ্রাহক ব্রাউজার থেকেই সাইটটি অ্যান্ড্রয়েড অ্যাপের মতো হোমস্ক্রিনে ইনস্টল করতে পারবে।
8. **গেমিং সাউন্ড ইফেক্টস ও কনফেটি:**
   - Web Audio API সিন্থেসাইজার দিয়ে বাটন ক্লিক, কয়েন ও পারচেজ সাউন্ড এবং কনফেটি এনিমেশন।

## 🚀 লোকাল মেশিনে চালানোর নিয়ম (Run Locally)

```bash
# ১. ডিপেনডেন্সি ইন্সটল
npm install

# ২. লোকাল সার্ভার চালু করুন

```

## 🌐 ফায়ারবেসে সম্পূর্ণ ফ্রিতে লাইভ করার নিয়ম (Free Deployment Guide)

এই সাইটটি সম্পূর্ণ ফ্রিতে ফায়ারবেস হোস্টিংয়ে হোস্ট করা যায়। কোনো ক্রেডিট কার্ডের প্রয়োজন নেই।

### ধাপ ১: Firebase CLI ইন্সটল ও লগইন
```bash
npm install -g firebase-tools
firebase login
```

### ধাপ ২: প্রোডাকশন বিল্ড তৈরি
```bash
npm run build
```

### ধাপ ৩: ফায়ারবেসে প্রজেক্ট ইনিশিয়ালাইজ ও ডিপ্লয়
```bash
firebase init hosting
# অপশনগুলোতে দিন:
# ? What do you want to use as your public directory? -> dist
# ? Configure as a single-page app (rewrite all urls to /index.html)? -> Yes
# ? Set up automatic builds and deploys with GitHub? -> No
# ? File dist/index.html already exists. Overwrite? -> No

firebase deploy
```

কমান্ডটি শেষ হলে ফায়ারবেস আপনাকে একটি ফ্রি লাইভ লিঙ্ক দিবে (যেমন: `https://your-project.web.app`), যা যেকেউ যেকোনো ডিভাইস থেকে ভিজিট করতে পারবে!
