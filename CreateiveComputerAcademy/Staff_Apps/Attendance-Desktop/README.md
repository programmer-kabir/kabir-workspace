# CCA Desktop Staff Attendance App 🚀

Creative Computer Academy (CCA) এর জন্য বিশেষভাবে তৈরি ডেডিকেটেড **Electron Desktop Attendance Application**।

## ✨ মূল ফিচারসমূহ:
1. **শুধুমাত্র হাজিরা (Attendance Only):** অপ্রয়োজনীয় মডিউল ছাড়া অত্যন্ত দ্রুতগতির, লাইটওয়েট অ্যাপ্লিকেশন।
2. **স্মার্ট পাঞ্চ ইন / পাঞ্চ আউট:** এক ক্লিকে Check In এবং Check Out।
3. **লাইভ শিফট টাইমার (Live Stopwatch):** অন-ডিউটি চলাকালীন রিয়েল-টাইম কতক্ষণ কাজ হয়েছে তা ডিসপ্লে করে।
4. **সিস্টেম ট্রে (System Tray Support):** 
   - অ্যাপ মিনিমাইজ করলে বা বন্ধ (X) করলে ব্যাকগ্রাউন্ডে ট্রে-তে চালু থাকে।
   - টাস্কবার ট্রে আইকনে রাইট ক্লিক করে "Quick Punch" বা "Open Attendance" করা যায়।
5. **হার্ডওয়্যার ও জিওফেন্সিং সিকিউরিটি:** স্বয়ংক্রিয় ডিভাইস প্রোফাইলিং এবং নিরাপদ অফিশিয়াল ভেরিফিকেশন।
6. **সাউন্ড ইফেক্টস ও নেটিভ নোটিফিকেশন:** চেক ইন বা চেক আউট সফল হলে সাউন্ড ও উইন্ডোজ নেটিভ নোটিফিকেশন প্রদান করে।

## 💻 যেভাবে চালাবেন (How to Run):

### অপশন ১: সরাসরি ডাবল ক্লিক (Instant Launcher)
রুট ডিরেক্টরির `run-attendance-app.bat` ফাইলে ডাবল ক্লিক করলেই অ্যাপ ওপেন হয়ে যাবে!

### অপশন ২: টার্মিনাল বা কমান্ড লাইন থেকে
```bash
# প্রোডাকশন বিল্ড রান করতে:
npm start

# অথবা ডেভেলপমেন্ট মোডে চালাতে:
npm run desktop:dev
```
